# @no0vie/brnchly-core

Framework-agnostic TypeScript APIs for brnchly evolution graphs, validation and serialization, layout, traversal, edge routing, playback, and viewport calculations.

## Install

```sh
npm install @no0vie/brnchly-core
```

## Usage

```ts
import { layoutGraph, validateEvolutionGraph } from "@no0vie/brnchly-core";
```

Requires Node.js 20 or newer. The package is ESM-only and includes TypeScript declarations.
