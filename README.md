# B_R_N_C_H_ly

Приложение для визуализации карьерного трека. Позволяет
сгенерировать формализованное резюме.

## Версия 1.0

### Сделано
- Сгенерирована базовая реализация с помощью DeepSeek
- Исправлена проблема с переворотом графика при смене направления
- Добавлена возможность темизации
- Добавить возможность добавлять точки на график по истории развития EvolutionStep

### Планируется

- Реализовать возможность добавления своих меток на графике в нижней или левой его части (точки роста ControlPoint)
- Реализовать возможность добавления элементов в список (ExperiencePoint -> GraphItem)
- Добавление карточек с информацией по узлу
- Исправление визуала компонентов и приведение его в приятный вид
- Исправление логики автопроигрывания (удалить ?)

- Генерация списка достижений в формате файла pdf или в формате слайдов по каждой добавленной ноде
